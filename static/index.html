它是怎么工作的

1

抓取入口页

解析首页 HTML，取出所有 <script src>、内联脚本与同源链接。

2

展开 JS 资源

下载 JS 文件，递归发现 webpack 懒加载 chunk，并尝试拉取 sourcemap 还原原始源码。

3

静态扫描

扫描字符串字面量，用 HTTP 调用上下文 + 业务关键词判断哪些是接口，并从调用参数里解析出 query / path / body 参数。

4

运行时采集

用本机 Chrome 打开页面跑一遍：记录真实请求；读 Vue Router 路由表精确区分页面路由；并把浏览器实际加载过的 JS 清单回灌给静态分析补抓。

5

汇总输出

静态与运行时结果合并去重，按置信度排序，导出 JSON / CSV / Markdown / HTTP 请求模板。

提示：静态阶段不主动请求发现的接口；运行时阶段会真实打开一次页面（会执行页面 JS，可能触发埋点）。请仅用于你有授权的站点。
